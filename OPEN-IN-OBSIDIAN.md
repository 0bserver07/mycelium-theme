# Obsidian Vault Location

**DO NOT open this root folder in Obsidian.**

Open this folder instead:

```
src/content/
```

## Why?

This repo contains both:
- Astro site (root folder) - for building the website
- Obsidian vault (src/content/) - for writing content

The vault with all plugins pre-configured is at `src/content/`.

## Quick Setup

1. Clone this repo
2. Run `npm install`
3. Open `src/content/` as your Obsidian vault
4. Run `npm run dev` to preview
