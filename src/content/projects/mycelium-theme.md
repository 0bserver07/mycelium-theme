# Mycelium Theme

A beautiful digital garden publishing system that connects your thoughts like the mycelium network connects trees in a forest.

## Features

- **Obsidian Integration**: Wikilinks, callouts, and embeds
- **Graph Visualization**: D3.js powered connection maps
- **Command Palette**: Quick search with Ctrl+K
- **Growth Indicators**: Seedling, budding, and evergreen status
- **Multiple Themes**: Forest, ocean, sunset, and more
