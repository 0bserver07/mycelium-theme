# Mycelium Sync Plugin

An upcoming Obsidian plugin that will make publishing to your Mycelium garden seamless.

## Planned Features

- **One-click publish** - Publish current note or entire vault
- **Draft management** - See draft status in Obsidian
- **Image optimization** - Auto-compress on publish
- **Link validation** - Check for broken wikilinks
- **Preview mode** - See how notes will render

## Technical Approach

The plugin will:

1. Read vault structure
2. Process frontmatter
3. Optimize assets
4. Sync to git repository
5. Trigger deployment

## Status

Currently in planning phase. Core functionality being designed.
