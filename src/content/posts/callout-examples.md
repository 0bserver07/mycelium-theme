# Callout Examples

Callouts are a great way to highlight important information. Mycelium supports all Obsidian callout types.

## Standard Callouts

> [!note] Note
> This is a note callout. Use it for general information.

> [!tip] Tip
> This is a tip callout. Great for helpful suggestions.

> [!info] Info
> This is an info callout. Perfect for additional context.

> [!warning] Warning
> This is a warning callout. Use when caution is needed.

> [!danger] Danger
> This is a danger callout. For critical warnings.

## Additional Callout Types

> [!success] Success
> Something worked! Celebrate the wins.

> [!question] Question
> Have a question? Use this callout to pose it.

> [!quote] Quote
> "The garden is a metaphor for the mind." — Unknown

> [!example] Example
> Here's an example of how to use something.

> [!abstract] Abstract
> A summary or overview of a concept.

> [!todo] Todo
> - [ ] Task one
> - [ ] Task two
> - [x] Task completed

> [!bug] Bug
> Document known issues or bugs here.

## Using Callouts

The syntax is simple:

```markdown
> [!type] Optional Title
> Callout content goes here.
```

See [[using-wikilinks]] for more syntax tips!
